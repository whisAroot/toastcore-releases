# ToastCore 1.0.0

แอปบน Windows สำหรับไลฟ์ TikTok: วิดเจ็ตบนจอไลฟ์ (นับชนะ, ตัวจับเวลา, อันดับของขวัญ/ถูกใจ, แจ้งเตือนของขวัญ),
อ่านแชทออกเสียง (TTS) และเปิดเสียงเมื่อได้รับของขวัญ

> ไม่มีอัปเดตอัตโนมัติ (ดาวน์โหลดเวอร์ชันใหม่แล้วติดตั้งทับได้เลย ข้อมูลเดิมยังอยู่) และตัวติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัล
> เกมจริงจะตามมาในเวอร์ชันถัดไป (ตอนนี้มีเกมตัวอย่างสำหรับทดสอบในหน้า **เกม**)

## ต้องมี
- Windows 10 หรือ 11 แบบ 64 บิต
- TikTok LIVE Studio (ถ้าจะใช้วิดเจ็ตบนจอไลฟ์)

## ติดตั้ง
1. ดับเบิลคลิก `toastcore-1.0.0-setup.exe`
2. ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน “Windows ได้ป้องกันพีซีของคุณ” ให้กด **ข้อมูลเพิ่มเติม** แล้วกด **เรียกใช้ต่อไป**
   (ขึ้นเพราะตัวติดตั้งยังไม่ได้ลงลายเซ็น ไม่ใช่ไวรัส)
3. เลือกโฟลเดอร์ติดตั้ง แล้วกดติดตั้ง จะมีไอคอน ToastCore บนเดสก์ท็อปและในเมนูเริ่ม

## เริ่มใช้งาน
1. เปิด ToastCore ไปที่ **แดชบอร์ด** ใส่ชื่อผู้ใช้ TikTok (จะมี @ หรือไม่ก็ได้) แล้วกดเชื่อมต่อ
2. ต้องกำลังไลฟ์อยู่จึงจะเชื่อมต่อได้ ถ้ายังไม่ไลฟ์ แอปจะลองเชื่อมต่อใหม่เองเป็นระยะ
3. ยังไม่ได้ไลฟ์? ไปที่หน้า **ทดสอบ** เพื่อส่งของขวัญ/แชทจำลองดูก่อนได้

## ระหว่างไลฟ์ (แดชบอร์ด)
- **คะแนน**: กด **ชนะ / แพ้ / เสมอ** นับเป็นรอบ ส่วน **−1 / +1** ใช้แก้คะแนนโดยไม่นับรอบ ตั้งคะแนน ตั้งเป้าหมาย และรีเซ็ตอยู่ในปุ่ม **⋯**
- บรรทัด **ล่าสุด** บอกว่าคะแนนเปลี่ยนเพราะอะไร ใครเปลี่ยน (แผงควบคุมหรือเกม) และเมื่อไร ถ้ากดพลาดให้แก้ด้วย −1 / +1
- **ตัวจับเวลา**: เริ่มจากปุ่มเวลาที่ตั้งไว้หรือ **กำหนดเอง** ระหว่างนับปรับได้ด้วย −30 วิ / +30 วิ / +1 นาที
  หรือพิมพ์จำนวนนาทีในช่อง เช่น `5` เพื่อเพิ่ม `-2` เพื่อลด (ลดจนเหลือ 0 จะหมดเวลาทันที)
- **ปุ่มลัดคีย์บอร์ด** (ใช้ได้ในหน้าแดชบอร์ด และไม่ทำงานตอนพิมพ์ในช่อง ใช้ได้ทั้งแป้นภาษาไทยและอังกฤษ):

| ปุ่ม | ทำอะไร |
|---|---|
| W | ชนะ |
| L | แพ้ |
| Space | พัก / นับต่อ ตัวจับเวลา |
| + | เพิ่มเวลา 30 วินาที |

- **กิจกรรมล่าสุด**: กดชิปเพื่อกรองประเภท ถ้าเลื่อนลงไปอ่าน รายการจะไม่เลื่อนหนี และมีปุ่ม “มีรายการใหม่ ↑” ให้กดกลับขึ้นบนสุด
- **อันดับ**: ของขวัญ / ถูกใจ 5 อันดับแรกของไลฟ์นี้ รีเซ็ตแยกได้

## Euler API key (ไม่บังคับ)
- แอปเชื่อมต่อ TikTok ผ่านบริการ Euler Stream ใช้ได้โดยไม่ต้องมีคีย์ แต่ถ้าเชื่อมต่อบ่อยอาจถูกจำกัดชั่วคราว
- สมัครคีย์ฟรีของคุณเองที่ https://www.eulerstream.com แล้วใส่ที่หน้า **ตั้งค่า → Euler API key**
- ในหน้าตั้งค่ามีลิงก์ไปสมัครคีย์ให้กดได้เลย
- คีย์เก็บไว้ในเครื่องของคุณเท่านั้น ไม่ได้มากับตัวติดตั้ง **อย่าแชร์คีย์ให้คนอื่น** เพราะจะใช้โควตาของคุณร่วมกัน

## เสียงอ่านแชทภาษาไทย
1. เปิด **การตั้งค่า Windows → เวลาและภาษา → เสียงพูด** (Speech)
2. ที่ “จัดการเสียง” กด **เพิ่มเสียง** เลือก **ภาษาไทย** แล้วรอดาวน์โหลดเสร็จ
3. ปิดแล้วเปิด ToastCore ใหม่ ไปที่หน้า **อ่านแชท** เลือกเสียงไทย แล้วกด **ทดสอบเสียง**

### เสียง Google (Chirp 3: HD) — ไม่บังคับ
- เสียงไทยที่เป็นธรรมชาติกว่า ต้องใช้ **คีย์ Google Cloud ของคุณเอง** (แต่ละบัญชีมีโควตาฟรีรายเดือนของตัวเอง เกินแล้วคิดเงิน)
- สร้างคีย์: Google Cloud Console → เปิด **Cloud Text-to-Speech API** → Credentials → Create API key
  แนะนำให้จำกัดคีย์ให้ใช้ได้เฉพาะ Text-to-Speech API และตั้ง **Budget alert**
- ในหน้า **อ่านแชท** เลือก “Google (Chirp 3: HD)” วางคีย์ กด **บันทึกคีย์** แล้วเลือกเสียงและกด **ทดสอบเสียง**
- คีย์ถูกเข้ารหัสเก็บในเครื่องนี้ แอปจะไม่แสดงคีย์อีก เมื่อเปิดใช้ ข้อความแชท (ที่ผ่านตัวกรองแล้ว) จะถูกส่งไปที่ Google
- ถ้า Google ใช้ไม่ได้ (คีย์ผิด เกินโควตา หรือเน็ตหลุด) แอปจะอ่านด้วยเสียง Windows แทน

## ใส่วิดเจ็ตใน TikTok LIVE Studio
1. ใน ToastCore ไปที่หน้า **วิดเจ็ต** กด **คัดลอก** ที่วิดเจ็ตที่ต้องการ
2. ใน LIVE Studio กดเพิ่มแหล่งที่มา → **ลิงก์** แล้ววางลิงก์ (เช่น `http://127.0.0.1:47800/overlays/win-counter/index.html`)
3. ตั้งขนาดตามตารางนี้ (ถ้าปรับ “ขนาด” ในแอป ให้คูณตามสเกลนั้น หน้าวิดเจ็ตจะแสดงขนาดที่แนะนำให้)

| วิดเจ็ต | กว้าง × สูง (px) |
|---|---|
| ตัวนับชนะ | 400 × 200 |
| ตัวจับเวลา | 400 × 150 |
| อันดับของขวัญ | 400 × 420 |
| อันดับถูกใจ | 400 × 420 |
| แจ้งเตือนของขวัญ | 500 × 160 |

- พื้นหลังโปร่งใสเป็นค่าเริ่มต้น ลิงก์จะไม่เปลี่ยน ยกเว้นเปลี่ยนพอร์ตในหน้าตั้งค่า
- ต้องเปิด ToastCore ไว้ตลอดไลฟ์ ถ้าปิดแล้วเปิดใหม่ วิดเจ็ตจะเชื่อมต่อกลับเอง

## ตัวจับเวลา (ของขวัญเพิ่ม/ลดเวลา)
- หน้า **ตัวจับเวลา**: ตั้งเวลาเริ่มต้นและเวลาสูงสุดของตัวจับเวลา (เป็นนาที)
- **กฎของขวัญ**: เลือกของขวัญ แล้วตั้งว่า **เพิ่มเวลา** หรือ **ลดเวลา** กี่วินาทีต่อ 1 ชิ้น (1–3600 วินาที, คอมโบ ×5 = 5 ชิ้น) รายการของขวัญมาจากที่เคยได้รับในไลฟ์และรายการที่มากับแอป
- **กฎตามระดับ** (S / M / L / XL): ใช้กับของขวัญที่ไม่มีกฎเฉพาะ ระดับดูจากจำนวนเหรียญ ตั้งเกณฑ์ได้ที่ **ตั้งค่า → ระดับของขวัญ**
- เพิ่ม/ลดเวลาเฉพาะตอนตัวจับเวลากำลังนับหรือพักอยู่ รวมแล้วไม่เกินเวลาสูงสุด ถ้าลดจนเหลือ 0 จะหมดเวลาทันที

## เสียง (อ่านแชท / เสียงของขวัญ)
- เสียงอ่านแชท และเสียงของขวัญเมื่อเลือก “เสียงของขวัญเล่นที่: แอปนี้” จะออกที่ลำโพงของเครื่อง ไม่ได้ส่งผ่าน LIVE Studio
  ให้เปิดลำโพงให้ไมค์ได้ยิน แบบเดียวกับที่เปิดเพลงตอนได้ของขวัญ
- แบบ “แอปนี้” จะเล่น 1 ครั้งต่อของขวัญ 1 ชิ้น (กุหลาบ ×5 = 5 ครั้ง) ตั้งจำนวนคิวสูงสุดได้ (ค่าเริ่มต้น 100) คิวเต็มจะไม่รับเพิ่ม

## ข้อมูลของแอปและการรีเซ็ต
- ตั้งค่า คะแนน และไฟล์เสียงเก็บที่ `%APPDATA%\ToastCore` (วางในช่องที่อยู่ของ File Explorer)
- ถอนการติดตั้งหรือติดตั้งใหม่ ข้อมูลยังอยู่
- อยากเริ่มใหม่ทั้งหมด: ปิดแอป แล้วลบโฟลเดอร์นั้น

## แจ้งปัญหา
ส่งมาว่า ทำอะไร → เกิดอะไรขึ้น → คาดว่าควรเป็นอย่างไร พร้อมภาพหน้าจอ เวอร์ชันของแอป (ดูได้ที่ **ตั้งค่า → ทั่วไป** หรือหน้า **เกี่ยวกับ**)
และไฟล์ `main.log` จาก **ตั้งค่า → ทั่วไป → เปิดโฟลเดอร์ log**
